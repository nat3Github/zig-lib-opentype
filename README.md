# opentype

A Zig library for parsing, shaping, hinting, and rasterizing OpenType and TrueType fonts. It covers `glyf`/CFF/CFF2 outlines, variable fonts (`fvar`/`gvar`/`avar`), COLR/COLRv1 color glyphs, the TrueType bytecode hinting VM, and CFF stem hinting. Text shaping implements GSUB/GPOS lookups plus complex-script pipelines for Arabic, Hebrew, Indic, Khmer, Myanmar, and the Universal Shaping Engine (USE), alongside Unicode bidi (UAX #9) and line-breaking (UAX #14). Font discovery is available as opt-in backends — Fontconfig, CoreText, DirectWrite, and Android — each compiled in only when its build option is enabled, so a consumer that only needs parsing/shaping/rasterization pays nothing for platform font matching. Most components are ported from a proven reference implementation (HarfBuzz, FreeType, font-kit) rather than derived from spec text by hand, and correctness is checked with a differential fuzz harness against those references. `parsing.zig` is the only code that touches attacker-controlled bytes; it bounds recursion, checks offset/length arithmetic for overflow, and caps allocations independent of header-supplied sizes. Public API surface is re-exported flat from `src/root.zig`. Requires Zig 0.16. Add it to `build.zig.zon` and `.addModule`/`.addImport` as `opentype` in your `build.zig`; discovery backends are toggled with `-Dfontconfig`, `-Dcore-text`, `-Ddirectwrite`, and `-Dandroid` (see `zig build -h`). This module ships without its test suite to stay lean for downstream consumers — tests live in the private parent repository.
